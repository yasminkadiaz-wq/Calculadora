# CALCULADORA

## 📝 Descripción
Este proyecto consiste en el desarrollo de una robusta y eficiente aplicación de calculadora desarrollada en Python. Su arquitectura está optimizada para procesar desde cálculos aritméticos fundamentales hasta funciones matemáticas de mayor complejidad, ofreciendo una experiencia fluida, precisa y totalmente estructurada para la resolución de operaciones en tiempo real.

## ⚙️ Operaciones
La calculadora está capacitada para ejecutar las siguientes 15 operaciones y funcionalidades matemáticas:

1. **Suma (+):** Adición de dos o más valores numéricos.
2. **Resta (-):** Sustracción de valores para la obtención de diferencias.
3. **Multiplicación (×):** Producto escalar entre factores.
4. **División (÷):** Cálculo del cociente exacto con control preventivo de errores para evitar divisiones entre cero.
5. **Módulo / Resto (%):** Obtención del residuo numérico resultante de una división entera.
6. **Potenciación ($x^y$):** Elevación de un valor base a un exponente determinado.
7. **Raíz Cuadrada ($\sqrt{x}$):** Cálculo del radicando principal en el dominio de números reales no negativos.
8. **Porcentaje (%):** Procesamiento proporcional de un valor sobre un total base.
9. **Factorial ($n!$):** Producto acumulativo de la serie descendente de números enteros positivos.
10. **Logaritmo Decimal ($\log_{10}$):** Evaluación de logaritmos en base 10 para análisis y modelado numérico.
11. **Seno ($\sin$):** Función trigonométrica fundamental para el análisis de ángulos.
12. **Coseno ($\cos$):** Razón trigonométrica del cateto adyacente sobre la hipotenusa.
13. **Tangente ($\tan$):** Razón trigonométrica directa entre el seno y el coseno.
14. **Valor Absoluto ($\vert{}x\vert{}$):** Conversión y normalización de cualquier magnitud a su equivalente positivo.
15. **Redondeo:** Ajuste dinámico de precisión decimal al entero o nivel de dígitos especificado.

## 🚀 Ejecución
Para clonar e iniciar este proyecto en tu entorno de desarrollo local, sigue estos pasos:

1. **Clonar el repositorio:**
   ```bash
   git clone [https://github.com/tu-usuario/tu-repositorio.git](https://github.com/tu-usuario/tu-repositorio.git)
   cd tu-repositorio
   ```

2. **Verificar el entorno de Python:**
   Asegúrate de contar con Python 3 instalado en tu equipo mediante la terminal:
   ```bash
   python --version
   ```

3. **Lanzar la aplicación:**
   ```bash
   python main.py
   ```
   *(Nota: Sustituye `main.py` por el nombre del archivo principal de tu código si es diferente).*

## 🛠️ Tecnologías
* **Python 3:** Seleccionado como el lenguaje de programación central por su potencia, alta legibilidad y paradigma limpio, permitiendo estructurar una lógica de negocio sólida y altamente escalable.
* **Módulo Nativo `math`:** Integración profunda de la biblioteca matemática estándar de Python para realizar cálculos de alta precisión, funciones trigonométricas y operaciones avanzadas sin incurrir en dependencias externas pesadas.
* **Manejo Riguroso de Excepciones:** Implementación de estructuras de control (`try-except`) para la gestión de errores en tiempo de ejecución (evitando cierres inesperados por entradas inválidas o indeterminaciones matemáticas).
* **Git & GitHub:** Utilizados para el control de versiones, la trazabilidad del código y el almacenamiento seguro del repositorio.
